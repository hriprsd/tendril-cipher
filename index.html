🪷 TENDRIL-1

An original, hand-made stream cipher — a climbing vine over a ring of nodes, twisting by a rolling wheel. Built to be attacked.

⚠️ NOT SECURE. This is a learning toy / break-me challenge, not real cryptography. Do not protect anything real with it. For that, use ML-KEM + AES-256-GCM.
ARX stream cipher golden-angle walk cycloid rotations ~40 lines

Try it

How it works (full spec — only the key is secret)

State: 32 bytes S[0..31] on a ring (the vine). Movers: growth pointer p, cycloid phase θ. GOLD = 157 (odd, coprime to 256; ≈0.613 turn, the golden-ratio conjugate).

per output byte:
  θ = (θ + 157) mod 256            # the wheel rolls
  p = (p + 1 + (θ >> 6)) mod 32     # tendril creeps forward, stride 1..4
  b = S[(p + 7)  mod 32]           # reach to older growth
  c = S[(p + 19) mod 32]
  r = 1 + (θ & 7)                  # twist amount 1..8
  m = rotl8((S[p] + b) mod 256, r) XOR c XOR θ
  S[p] = m                         # grow the node
  out  = m XOR S[m mod 32]         # nonlinear tap

encrypt = plaintext XOR keystream   (decrypt is identical)
init: S[i] = (i*157 + key[i%|k|] + nonce[i%|n|]) mod 256, then 64 warmup steps

It's an ARX (add-rotate-xor) cipher — the ChaCha/BLAKE toolkit — but the engine is original: an ARX ring-walk with a golden-angle pointer and cycloid-driven rotations. Not RC4 (swap-based), not ChaCha (fixed matrix).

Where to attack (hints)

  • Keystream bias. Generate megabytes of keystream and look for byte-value or positional biases (this is how RC4 — and WEP — fell).
  • Tiny state. 32 bytes + two pointers. Is the effective state really that small? Short cycles? Internal collisions?
  • Arbitrary constants. The offsets 7 and 19, state size 32, rotation scheme — chosen, not justified. Weak diffusion is likely.
  • Key schedule. The init is simple and linear-ish before warmup. Related keys / related nonces may correlate.
  • Known-plaintext. The challenge hands you 18 keystream bytes. Does that constrain the key enough to search?

TENDRIL-1 is a toy for learning cryptanalysis. If it breaks, that's the lesson; if it survives a while, that only means no one has broken it yet — which is not the same as secure. Real, quantum-safe encryption: ML-KEM (Kyber) + AES-256-GCM.
